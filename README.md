# Applied Data Analytics and Machine Learning — FYS-STK3155

Course projects for **FYS-STK3155: Applied Data Analytics and Machine Learning** at the **University of Oslo (UiO)**. This repository explores fundamental machine-learning methods, from regression and numerical optimization to neural networks, with an emphasis on implementing algorithms and evaluating their performance.

## Projects

### Project 1 — Regression Analysis, Resampling Methods and Gradient Descent

Polynomial regression applied to Runge's function, comparing **ordinary least squares (OLS), Ridge and Lasso**. The project also explores model complexity, the bias–variance trade-off, bootstrap resampling, cross-validation, and gradient-based optimization methods.

### Project 2 — Classification, Regression and Neural Networks

Development of **feed-forward neural networks and backpropagation** in Python, with experiments involving activation functions, network architectures, optimizers, learning rates, and regularization. The project examines both regression and classification and compares neural-network approaches with established methods.

## Repository contents

Each project directory contains its Python code, experiments, generated figures, and a report describing the methodology and results.
